# 🛡️ CyberGuard — Защита от DDoS и взлома

**CyberGuard** — это информационный сайт, посвящённый кибербезопасности. Здесь собраны актуальные методы защиты от DDoS-атак, веб-уязвимостей и киберугроз с учётом реалий для Украины, России и мира.

Проект создан для повышения осведомлённости IT-специалистов, владельцев сайтов и обычных пользователей о современных угрозах и способах их предотвращения.

## ✨ Особенности проекта

- **Чистый HTML/CSS** — без внешних зависимостей, легко кастомизировать
- **Адаптивный дизайн** — корректно отображается на любых устройствах
- **Тёмная тема** с неоново-зелёными акцентами (стиль кибербезопасности)
- **Готовые примеры конфигурации** (nginx rate limiting, код SQL-инъекции)
- **Таблица инструментов безопасности** (Nmap, Burp Suite, WPScan и др.)
- **Региональный раздел** — особенности защиты в Украине и России
- **Бесплатное развёртывание** на Vercel / GitHub Pages

## 🧩 Структура сайта

| Раздел | Содержание |
|--------|------------|
