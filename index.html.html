🛡️ Защита от DDoS-атак

⚡ Что такое DDoS?

DDoS (распределённая атака типа «отказ в обслуживании») — это попытка сделать ресурс недоступным для легальных пользователей путём перегрузки сервера огромным количеством запросов из множества источников. Чаще всего атакуют через ботнеты — сети заражённых устройств.

🚫 Основные методы защиты

  • Cloudflare / AWS Shield / Akamai — профессиональная фильтрация трафика
  • Rate limiting — ограничение частоты запросов с одного IP
  • Балансировка нагрузки — распределение трафика между серверами
  • Web Application Firewall (WAF) — блокировка вредоносных паттернов
  • GeoIP-фильтрация — блокировка подозрительных регионов (при необходимости)

🖥️ Пример настройки nginx (rate limiting)

limit_req_zone $binary_remote_addr zone=one:10m rate=10r/s;
server {
    location / {
        limit_req zone=one burst=20 nodelay;
    }
}

🛡️ Cloudflare WAF

Автоматически блокирует SYN-flood, UDP-атаки, атаки на уровне приложений (HTTP). Бесплатный тариф включает базовую DDoS-защиту. Для сайтов любой сложности.

🏠 Для малого сайта

Используйте плагины типа Wordfence (для WordPress), настройте fail2ban, подключите кэширование страниц и включите «режим ожидания» в Cloudflare (Under Attack).

🔐 Защита от взлома сайтов и серверов

🧨 Основные уязвимости (OWASP Top 10)

  • 🔹 SQL-инъекции
  • 🔹 XSS (межсайтовый скриптинг)
  • 🔹 CSRF (подделка межсайтовых запросов)
  • 🔹 Небезопасная конфигурация
  • 🔹 Утечка данных через debug-режим

✅ Практические советы

  • ✔️ Используйте подготовленные запросы (параметризация)
  • ✔️ Включите CSP (Content Security Policy)
  • ✔️ Регулярно обновляйте все библиотеки и CMS
  • ✔️ Отключите вывод ошибок на production
  • ✔️ Настройте двухфакторную аутентификацию для админки
  • ✔️ Проводите регулярные аудиты безопасности

⚠️ Пример SQL-инъекции (опасно!)

Никогда не вставляйте данные пользователя прямо в запрос:

SELECT * FROM users WHERE name = '"+user_input+"'

Замените на параметризованный запрос (например, SQLAlchemy, PDO, Entity Framework).

📦 Инструменты защиты

  • ModSecurity (WAF) — открытый WAF для Apache/Nginx
  • ClamAV — антивирус для загружаемых файлов
  • OSSEC — обнаружение вторжений (HIDS)
  • Fail2ban — блокировка bruteforce

🔒 HTTPS + HSTS

Обязательно включите HTTPS (Let's Encrypt бесплатно). Добавьте заголовок HSTS, чтобы браузер всегда обращался через защищённое соединение. Это предотвращает перехват сессий (MITM).

🌍 Особенности в России, Украине и мире

🇺🇦 Украина

После 2022 года уровень DDoS-атак на государственный и банковский сектор вырос на 300-500%. Для защиты используют «Дія» Security, хостинг в облаках с защитой, а также резервные каналы связи. Рекомендовано иметь кэширующие резервные DNS и распределение серверов по Европе.

🇷🇺 Россия

В РФ действует закон о «суверенном Рунете» и обязательной фильтрации трафика. Провайдеры блокируют подозрительные атаки, но бизнесу стоит использовать RuCenter DDoS-Guard, StormWall, Qrator. Учитывайте угрозы, связанные с блокировкой сайтов по IP.

🌍 Мировой опыт

Во всем мире популярна защита через Anycast-сети (Cloudflare, AWS Global Accelerator). Рекомендуется следить за дайджестами CISA, иметь план реагирования на инциденты и регулярно делать бэкапы офлайн.

📌 Дополнительные меры

Настройте мониторинг через Prometheus + Grafana. Включите уведомления при аномальном трафике. Используйте CDN для статики. Для особо важных сервисов заключите контракт с провайдером защиты от DDoS (On‑premise решения).
